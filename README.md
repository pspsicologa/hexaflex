# hexaflex
Este é um infográfico inteligente e interativo baseado no modelo DNA-V (uma variante da Terapia de Aceitação e Compromisso - ACT).

O projeto utiliza a API do Gemini para fornecer exercícios práticos de flexibilidade psicológica em tempo real.✨ 

Funcionalidades com IA
Tradutor do Conselheiro: Pratique a defusão cognitiva transformando pensamentos críticos em observações do "Eu Observador".
Desafios do Descobridor: Gere sugestões de pequenas ações para expandir sua zona de conforto.
Refúgio da Compaixão: Receba mensagens de autocompaixão baseadas nos princípios da ACT.
Identificador de Valores: Analise suas ações diárias para encontrar o propósito e valor por trás delas.

🛠️ Tecnologias Utilizadas
HTML5 / Tailwind CSS (Design Responsivo)
Chart.js (Gráficos Dinâmicos)
Google Gemini API (Processamento de Linguagem Natural)🚀 

Como usar: Obtenha uma chave de API no Google AI Studio.Abra o arquivo index.html.Insira sua chave no campo de configuração ou diretamente no código na variável apiKey.

Nota: Este projeto tem fins educacionais e de demonstração de tecnologia.
